# ice-skaters papers

| File | What it is |
|---|---|
| `ice-skaters-jss.tex` / `ice-skaters-jss.pdf` | The paper, JSS format: package, study, ablation, and the regret-transfer theorem with proofs. `./compile_paper.sh` rebuilds it (tectonic). |
| `regression-frontend.md` | Preliminary results: the calibrated forecast front-end for online regression, three prongs plus the mu-vs-z ablation, measured cost, and the revised recommendation. |
| `regret-transfer.md` | The theorem: pathwise regret transfer with measured constants, the insurance corollary, and the oracle decomposition, with proofs and a numerical bound check. |

The full results log, protocols and harnesses live in the
[timemachines](https://github.com/microprediction/timemachines) repo,
`benchmarks/RESULTS.md` section 6.
